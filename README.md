# video-creator

Simple browser-based video creator. No install needed.

## How to use

1. Open `index.html` in a browser, or enable GitHub Pages for this repository.
2. Upload 1 or more images.
3. Add a title and subtitle, choose how long each image shows and a background colour.
4. Click **Preview** to watch the slideshow on the canvas.
5. Click **Record video** to export it as a `.webm` video, then **Download video**.

## Files

- `index.html` — the app page
- `style.css` — styling
- `app.js` — slideshow, canvas drawing and video recording (Canvas + MediaRecorder)

## Notes

- Video is recorded in your browser at 1280x720, no upload to a server.
- For best results use landscape images.
